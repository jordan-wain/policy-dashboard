How This Works

▶

Every number traces back through a single pipeline — from regulator publication to the positions we took.

📄
1. We Respond
Policy team files a consultation response. Logged in the Policy Tracker with a link to the Google Doc.
📰
2. Final Rule Drops
Regulator publishes final rule / policy statement. Someone logs the reference in the Tracker's Final Rule Ref column.
⚙️
3. Workflow Triggers
The assessment workflow detects rows where Final Rule Ref is filled but Impact Status is empty. Pulls our response text + final rule.
🔬
4. Positions Assessed
LLM extracts our positions, compares against final decisions, deduplicates into distinct asks, scores each as adopted / partial / rejected / deferred.
📊
5. Results Flow Up
Influence rate written back to Tracker. Results aggregate: response → agency → jurisdiction → global dashboard.
Aggregation chain: Individual positions → deduplicated per response → combined per agency (FCA, FinCEN...) → rolled up per jurisdiction (UK, US...) → global headline
